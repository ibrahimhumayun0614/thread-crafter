# Thread Crafter

A lightweight, frontend-only Twitter/X thread crafter. Paste or write long-form content, preview the generated tweet-sized thread in real time, and copy either individual tweets or the full thread.

## Features

- React + TypeScript + Tailwind CSS
- shadcn/ui-inspired black-and-white interface
- 280-character tweet splitting with thread numbering
- Live character and tweet counters
- Copy individual tweets or the full thread
- Clear/reset and sample content actions
- Optional browser `localStorage` draft saving
- No backend, database, auth, or Twitter/X API

## Run Locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
